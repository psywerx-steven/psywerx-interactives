# Non-governed two-pass research workspace

This empty envelope is not production science. Pass A uses existing Relationship
V1 contracts for candidates/evidence and structured questions, dispositions,
ownership, source queue and unresolved items. Pass B uses Actions & Events types,
occurrences, effects and source findings. A generated template has no candidates.

All scientific candidates must remain non-governed and NOT_ELIGIBLE. This workspace
cannot provide human authority. Boolean section-readiness is an auditable review
attestation, not a scientific approval or reason to invent relationships.
Cross-Family handoffs share issue identities; use source-Family ownership for
directed claims, lexical Family ownership for symmetric claims, and exact edge
ownership for modification claims. Preserve rejections and no-finding outcomes.
