# Cross-level exposure reference implementation

**Status:** NON-PRODUCTION PROTOTYPE ONLY

The prototype selects reusable immutable `CrossLevelExposureMapping` profiles plus immutable Relationship-specific `CrossLevelExposureBinding` records. Model 1 (Relationship-specific mappings) duplicated route semantics; Model 2 separates reusable routing semantics from exact Relationship hashes, entity pairs, qualifiers, context, evidence and subsets. Four mappings and five bindings test the three real positive controls, reuse, and discrete assignment through existing `HT-V1-SOC-F07-002`. No production consumer imports the prototype.
