# Informational construct boundaries

**ADVISORY — HUMAN DECISION REQUIRED. No definition, alias or classification change is authorized.**

| Boundary | Layer finding |
|---|---|
| Availability / exposure / attention | `INF-002`, actual encounter and `PSY-056` are distinct. Availability alone does not establish message receipt. |
| Volume / load | `INF-006/007/008/009` describe information amount or rate; `PSY-057` is a recipient processing state. |
| Objective / perceived property | Clarity, evidence quality, provenance, veracity and threat wording cannot be substituted for their recipient appraisals. |
| Source property / source perception | `INF-034/035` differ from `PSY-113`; a provenance trail can reveal a poor source. |
| Repetition / belief | `INF-041` can affect familiarity under exposure; belief confidence and truth remain distinct. `CONTRIB-PSY-LAYER-REPETITION-001` stays blocked. |
| Framing / preference | `INF-017` changes task representation; a risky task choice is not stable `PSY-084` loss aversion. |
| Argument quality / acceptance | `INF-027` and `PSY-114` require separate objective and perceived coding; neither proves claim acceptance. |
| Norm claim / actual norm / perceived norm | `INF-061`, any measured Social norm and `PSY-016` have separate referents and measurement. |
| Guidance / action | `INF-069/070/071/072/073` do not establish an internal plan or actual behavior. |
| Correction / universal debiasing | Exact correction, claim, timing and recipient conditions matter; no generic backfire or cure follows. |
| Threat or efficacy claim / appraisal | `INF-056/057/058` are message content, not `PSY-009/010` or behavior. |
| Tailoring / relevance | `INF-055` personalization is not automatically `PSY-007` perceived relevance. |
| Conceptual / surface complexity / readability | `INF-013` overlaps `INF-077` in the frozen definitions; `INF-014` is audience-relative. Pilot `HYP-INF-F03-H20` and blocked INF-077 metadata remain unresolved. |

Most message experiments combine components. The `BUNDLED_MANIPULATION` reason is used wherever a single content property cannot be identified. These distinctions are checks on candidate claims, not proposed ontology edits.
