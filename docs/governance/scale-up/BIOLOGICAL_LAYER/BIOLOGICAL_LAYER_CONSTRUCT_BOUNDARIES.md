# Biological Layer construct boundaries

**ADVISORY — HUMAN DECISION REQUIRED. New GOVERNED = 0; new ACTIVE = 0.**

The audit keeps biomarker separate from biological Driver, physiological state from subjective report, acute from chronic, stable susceptibility from acute state, administered drug from realized pharmacologic effect, and realized effect from behavior. Dependence, cessation and withdrawal are distinct. Chronological age does not itself specify aging mechanism. Clinical cohorts do not automatically transfer to the general population. Homeostatic feedback can be nonlinear; physiological correlation does not set causal direction; task performance is not broad capacity.

Specific unresolved cases are iron-trial general fatigue versus `BIO-025` physical fatigue, cytokine level versus `BIO-030` whole sickness response, polygenic score versus mechanism, frailty scale overlap with physical fitness, and caffeine symptom frequencies versus aggregate `BIO-066` severity. No definition, alias or ontology class is changed.
