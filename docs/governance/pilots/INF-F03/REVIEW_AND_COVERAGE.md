## Skeptical corrections and retained uncertainty

- Noise: reduced output quantity cannot establish reduced normalized complexity;
  inspected ratio measures were nonsignificant, not equivalence evidence.
- Syntax: performance/reading-time proxies are not occupied cognitive capacity.
- Economic messages: conceptual-complexity and source-sentiment measures need
  alignment before an exact INF-013 → PSY-113 assertion is ready.
- Uncertainty: numeric/verbal and uncertainty-type distinctions are retained;
  source credibility does not establish metacognitive accuracy calibration.
- Editing: only selected directly manipulated text features are proposed for
  review. No automatic comprehension, fit, completeness or universal benefit.
- RDS: completeness ratios, contradiction/cohesion rules and message–audience
  fit do not acquire independent causal agency through an event label.
- Moderation: trait span or study-level culture cannot be converted into an
  exact canonical moderator edge. No pathway is inferred from adjacency.
- Unknown effect direction is not zero. No package or practitioner recommendation
  is inferred. Owner-family assignment records consultation requirements, not
  consultation having occurred.

## Remote-action boundary

The repository governance workflow triggers pull requests to main and pushes to
main; it has read-only contents permission and validation jobs. Pilot changes add
only validation steps. No workflow dispatch, Pages/deployment command, settings
change or merge is part of this pilot. PR CI is mechanical validation, not human
scientific approval. The pre-existing Pages main-merge boundary is not crossed.

## Reproduction and limitations

`build_inf_f03_pilot.py` renders reviewed inputs; it does not discover claims.
`validate_inf_f03_pilot.py` tests committed HEAD in disposable clones and records
the original checkout's before/after protected-byte comparison. It includes
production schemas, lifecycle/source validation and the existing deterministic
migration/BIO materializers without running those materializers on user data.

The coverage ledger demonstrates structured screening, not exhaustive retrieval.
Exact causal lag, persistence, quantitative effect sizes and unresolved RDS
operational versions remain absent. This pilot does not certify a complete graph.
