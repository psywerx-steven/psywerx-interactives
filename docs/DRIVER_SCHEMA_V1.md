# PSYWERX Driver Schema v1.0

This canonical public-driver schema is derived from the common Drivers table
and embedded Codebook in the standardized Biological, Psychological, and
Social ontology workbooks. All three workbooks use the same 27 spreadsheet
columns in the same order.

Every generated record has every canonical JSON key. An absent optional scalar
is null; an absent optional list is an empty array. Required values must be
present and non-empty. The importer reports missing optional columns as
warnings and missing required columns as errors.

## Validation behavior

The importer requires one driver table per workbook, compares the complete
header signature across workbooks, validates every required value, and reports
optional omissions and unexpected columns. It rejects conflicting layer
evidence, duplicate IDs, invalid record types, and non-canonical layers.
Duplicate normalized names within a layer are reported as warnings.

All non-driver worksheets are intentionally skipped. The importer builds the
complete combined dataset in memory and atomically replaces data/drivers.json
only when validation finishes without errors.
